# Taijifu Legacy

Novo repositório-base da franquia Taijifu. Este projeto nasce separado do protótipo anterior e começa com uma fundação limpa para um jogo de luta em Godot 4.

## Estado atual

Sprint 0 aplicada: estrutura inicial, documentação base, cena principal provisória e projeto Godot preparado para crescimento.

## Objetivo do projeto

Criar um jogo de luta com identidade própria, progressão por builds, combate técnico, modos de carreira e expansão modular.

## Estrutura inicial

- `project.godot` — configuração do projeto
- `scenes/` — cenas do jogo
- `scripts/` — lógica do jogo
- `assets/` — arte, áudio, VFX e UI
- `docs/` — design, arquitetura e roadmap

## Como abrir

1. Instale o Godot 4.3 ou superior.
2. Abra a pasta do repositório no editor.
3. Execute a cena principal `res://scenes/main.tscn`.

## Sprint 0 entregue

- visão inicial do jogo;
- roadmap de sprints;
- arquitetura base;
- cena inicial provisória;
- projeto Godot pronto para evolução.
