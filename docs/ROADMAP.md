# Roadmap — Taijifu Legacy

## Sprint 0 — Fundação

Objetivo: preparar o repositório para receber o jogo principal sem mistura com o protótipo anterior.

Entregas:
- visão do projeto;
- escopo inicial;
- estrutura de pastas;
- configuração do Godot 4;
- cena principal provisória;
- convenções técnicas.

## Sprint 1 — Núcleo do combate

- separar movimento, combate, defesa, recursos e equipamento;
- criar dados básicos de ataques e técnicas;
- validar um vertical slice jogável.

## Sprint 2 — Profundidade

- builds;
- elementos;
- postura;
- desarme;
- ecos de técnica;
- arena com rota e pressão.

## Sprint 3 — Conteúdo e progressão

- carreira;
- ranking;
- modos adicionais;
- história;
- desbloqueáveis.

## Sprint 4 — Polimento e lançamento

- balanceamento;
- performance;
- UI final;
- áudio;
- arte;
- build pública jogável.
